# Service Page Images

This directory contains hero images for the service pages. The following images are required:

- dynamics365-hero.jpg - Hero image for the Dynamics 365 Implementation & Architecture page
- azure-hero.jpg - Hero image for the Azure Cloud Architecture & Integration page
- power-platform-hero.jpg - Hero image for the Power Platform Custom Development page
- ai-copilot-hero.jpg - Hero image for the AI & Copilot Integration page
- integration-hero.jpg - Hero image for the Integration Architecture page
- transformation-hero.jpg - Hero image for the Digital Transformation page

These images should be high-quality, professional images that represent the respective services. The recommended dimensions are 1920x1080 pixels.

For the initial development phase, you can use placeholder images from Unsplash or similar services. For production, consider using custom photography or licensed stock images that align with Fred Adun's brand identity.
